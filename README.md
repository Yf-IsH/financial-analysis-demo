# 财报分析 Demo

一个本地运行的财务报表分析 demo。输入美股上市公司名称或股票代码后，应用会从 SEC EDGAR 的真实 XBRL 数据中抓取公司事实数据，整理三大表、计算专业财务指标、展示时间趋势，并支持两家公司专业指标对比。

## 功能

- 公司搜索：支持公司名称、Ticker、CIK 模糊搜索。
- 三大表查看：资产负债表、利润表、现金流量表。
- 专业指标计算：根据 `需要包含的财务指标.xlsx` 纳入可由当前数据源计算或近似计算的专业指标，指标名称可点击查看公式、内涵和数据说明。
- 杜邦分析：单独展示 `净资产收益率 = 销售净利率 × 总资产周转率 × 权益倍数`。
- 时间趋势：收入、净利润、经营现金流、资产、负债、权益等关键项目趋势。
- 可比公司对比：输入另一家公司后，对比专业财务指标。

## 指标覆盖说明

页面现在只展示可计算或可合理近似的指标。仅靠 SEC companyfacts 无法可靠计算的市净率、市盈率、每股净资产、股利收益率、本量利分析系列公式、杠杆系数已经从页面中移除。

部分指标使用 SEC 可得科目近似：

- 应付账款周转率：采购成本暂用营业成本近似。
- 成本费用总额/成本费用利润率：按营业成本、经营费用、利息费用等可得科目近似。
- 股利支付率：用现金股利总额/净利润近似。
- ROCE：资本总额用有息债务平均余额+股东权益平均余额近似。

## 数据源

数据来自 SEC EDGAR 公开接口：

- `https://www.sec.gov/files/company_tickers.json`
- `https://data.sec.gov/api/xbrl/companyfacts/CIK##########.json`

应用不会使用样例数据；如果某家公司缺少某个科目，会在页面显示为空值。

## 运行

```powershell
python app.py
```

然后打开：

```text
http://127.0.0.1:8000
```

首次查询需要联网下载 SEC 数据，缓存会写入本目录下的 `.cache` 文件夹。

## 说明

SEC XBRL 标签在不同公司之间可能存在披露差异，本 demo 为了可读性会在常见 US-GAAP 标签之间做兼容匹配。它适合用于演示和初步分析，不构成投资建议。
